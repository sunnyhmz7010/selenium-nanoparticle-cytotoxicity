最终源表为[实验数据归档](../external_702_20261101_confirmed/source_experiments.xlsx)，SHA-256：`2915943684743d587b1c397c834da2a59fb41e7032847825291a1cbca941e774`。702条记录逐格核对，只有接种密度列变化，其余七列完全一致。

23万和30万分别是10 mL细胞悬液中的总细胞数，每孔取0.1 mL，因此HUVEC为2300个/孔、H9C2为3000个/孔。此前记录为230000和300000个/孔，放大100倍。本次以最终源表及用户对接种过程的更正为准。

## 对实验发现的影响

实验实际接种数量与现在确认的每孔数量一致。存活率报告值未变，实测剂量—时间曲线、实测材料排序、描述性性质关联和实验侧IC50均不变。实验侧54条曲线中24条可插值、30条超过512 μM；模型侧54条仍全部未达到50%阈值，没有有限IC50配对可计算普通误差或R²。

两种细胞接种数量仍不同，H9C2在历史编码器中仍为未知细胞类别、组织字段仍缺失；这两项限制不能因密度更正而消失。体系间差异不能单独解释为细胞类型的因果效应。
