\section{计算方法}

\subsection{数据来源与整理流程}
本研究采用两类数据。第一类为大规模多类型纳米颗粒基准数据集，用于比较不同模型在异质表格数据上的一般性能。该数据集覆盖金属、金属氧化物、聚合物、碳基与无机纳米颗粒，清洗后获得 4102 个有效样本。第二类为自建硒纳米颗粒毒性验证数据集，用于构建面向 SeNPs 的专用预测模型。该数据集由课题组基于文献逐条整理，统一浓度单位、核对检测条件并清除明显错误记录后，形成用于增强特征实验的硒纳米颗粒数据表。

在数据预处理阶段，连续变量统一转换为数值型并进行缺失值检查；类别变量采用统一命名和编码；浓度、暴露时间、粒径、Zeta 电位、细胞类型、检测方法与修饰基团等作为基础特征输入。对分类任务，以细胞存活率 85\% 作为毒性阈值构建二分类标签。对于硒纳米颗粒专用建模，在基础特征之外进一步整理出 IC50、元素 Se 含量、长期稳定性、结合能 Se3d 以及晶型编码等增强特征。

\subsection{特征设置}
基础特征包含以下几类信息：暴露条件（浓度、时间）、颗粒理化属性（粒径、Zeta 电位、尺寸比、表面电荷）、生物体系属性（细胞类型）以及实验条件（检测方法、修饰基团）。增强特征包括：
\begin{itemize}
  \item IC50\_uM；
  \item 元素 Se 含量（wt\%）；
  \item 长期稳定性（周）；
  \item 结合能 Se3d（eV）；
  \item 晶型编码。
\end{itemize}
在自动特征选择阶段，保持基础特征不变，对上述五个增强特征的全部非空组合进行穷举搜索，共 31 种组合，以三折交叉验证 MAE 作为筛选指标。

\subsection{模型架构}
本研究比较了树模型、注意力增强树模型以及深度表格模型三类架构。

\subsubsection{随机森林}
随机森林由多棵决策树组成，通过自助采样与特征随机子采样降低方差。该模型能够自然处理非线性关系和特征交互，并对中小规模表格数据具有较强鲁棒性。本文将其作为最核心的基线模型之一，同时用于增强特征后的高精度回归建模。

\subsubsection{XGBoost}
XGBoost 采用梯度提升框架，按残差逐步迭代生成树模型，并通过正则化控制复杂度。相比随机森林，XGBoost 更擅长拟合复杂的非线性映射，因此在增强特征齐全时能够进一步提升硒纳米颗粒毒性预测精度。本文的最终主结果模型即为增强特征下的 XGBoost。

\subsubsection{ABRF 与 LARF}
ABRF 与 LARF 为在随机森林基础上引入注意力机制的树模型变体。ABRF 对树级输出进行加权，LARF 进一步在叶节点层面引入注意力分配，用于测试注意力机制是否能够提升中小样本表格建模能力。

\subsubsection{TabTransformer 与蒸馏 TabTransformer}
TabTransformer 通过将类别特征映射为嵌入向量，并利用 Transformer 编码器建模特征间依赖关系；数值特征则在后续与编码结果融合。蒸馏 TabTransformer 在此基础上进行压缩，以降低参数量和推理成本。本文将其作为深度表格模型代表，用于与树模型进行对照。

\subsection{训练与验证策略}
对于大规模多类型纳米颗粒基准数据集，采用 7:3 训练测试划分，以测试集性能作为主要比较依据。对于硒纳米颗粒数据集，采用三折交叉验证，以 CV MAE 和全量 $R^2$ 作为主要回归评价指标。分类任务采用 Accuracy、F1 和 AUC 作为评价指标。所有模型均在相同数据划分下比较，以保证结果公平。

\subsection{模型选择原则}
模型选择遵循“性能优先、稳定性优先、部署可行”的原则。若增强特征可获得，则优先采用 XGBoost 作为高精度回归主模型；若更强调鲁棒性、解释性和后续平台部署，则优先采用随机森林。对于增强特征筛选，不采用手工经验判断，而是通过穷举搜索与交叉验证自动确定最优特征子集。
