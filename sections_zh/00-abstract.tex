纳米硒（SeNPs）因具有良好的生物相容性和多重生物活性而受到广泛关注，但其毒性效应受粒径、浓度、表面修饰和材料化学状态等因素共同影响，传统实验方法难以快速完成系统评估。本文围绕纳米硒细胞毒性预测问题，构建了“基准数据集模型比较 + 专用数据集增强特征建模”的研究框架。首先，在来源于 Masarkar 等人的多类型纳米颗粒公开数据集上，对随机森林、XGBoost、ABRF、LARF、TabTransformer 和蒸馏 TabTransformer 进行了系统比较；随后基于课题组整理的 310 条硒纳米颗粒有效样本，进一步开展专用模型训练与增强特征筛选。

结果表明，在大样本异质表格数据上，TabTransformer 在回归任务中取得最高 $R^2$（0.768），而树模型在分类任务中表现更稳定，其中 XGBoost 的 AUC 为 0.945。在硒纳米颗粒专用数据集上，增强特征显著优于基础特征：XGBoost 在增强特征设置下取得最佳结果，三折交叉验证 MAE 为 7.20\%，$R^2$ 为 0.957；随机森林在增强特征下也达到较高精度（MAE 7.63\%，$R^2$ 0.915）。进一步的自动筛选表明，IC50、元素 Se 含量、长期稳定性和结合能 Se3d 构成最优增强特征子集，其性能与全增强特征集基本一致。

本研究说明，面向单一材料体系的毒性预测，仅依赖通用理化参数是不够的，能够刻画材料本征化学属性的增强特征更为关键。所构建的建模流程和结果可为纳米硒毒性预测平台开发、实验优先级筛选及后续外部验证研究提供方法基础。
