# NanoTox Assistant 交付文件

纳米硒细胞毒性预测与交互解释工作台，附本次确认的两版最终软件演示视频。

## 最终视频

| 文件 | 配乐 | 时长 | 规格 |
|---|---|---:|---|
| [A 版](videos/NanoTox-Assistant-A版-若如初见-原速.mp4) | 《若如初见》原速 | 68.68 秒 | 1920 × 1080，H.264 / AAC |
| [B 版](videos/NanoTox-Assistant-B版-Cat-Walk.mp4) | Cat Walk | 69.20 秒 | 1920 × 1080，H.264 / AAC |

两版均含软件用途介绍、真实 ego 窗口操作、完整助手提问与回复、实验对照、SHAP 和 IC50 动画。配乐有各自的节拍安排。

## 启动平台

Python 3.12。在克隆后的仓库根目录执行以下 PowerShell 命令，安装到独立虚拟环境。

```powershell
cd NanoTox-Assistant
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe platform\studio_server.py
```

打开 <http://[::1]:18766/>。本地服务仅监听 IPv6 回环地址 `::1`；关闭运行脚本的终端或按 Ctrl+C 停止。

默认端口 18766 如已被旧版本占用，先停止那个服务。数据、模型和页面均包含在当前文件夹中，可以将整个 `NanoTox-Assistant` 文件夹复制到其他目录运行。

## 已实现的操作

- 输入材料、粒径、Zeta 电位、剂量和暴露时间，调用冻结随机森林重新预测并计算 Tree SHAP。
- 助手根据本次推理结果回答贡献、单位换算、实测匹配和上次预测的差异；当前实现为本机证据规则问答。
- 剂量曲线、材料排序、实验与模型 IC50 对照、逐样本贡献、配对记录及 CSV 导出。

视频保留录制时的历史画面。当前平台按2026-11-03更正的HUVEC 2300个/孔重新计算：CS-SeNPs、114.72 nm、+33.36 mV、72 h下，512 μmol/L Se的预测存活率为54.1100%；320 μmol/L时为54.6425%，变化为+0.5325个百分点。320条件没有完全匹配的归档实测值。

## 数据与模型

`data/` 是 `research/results/huvec_external_20261013_umol_se/` 中运行平台所需的七张表，含 351 个条件、9 种材料和 27 条材料—时间曲线。单位为 μmol/L Se，输入模型时乘以 0.078971 换算为 μg/mL。

`models/` 包含录制时使用的基础随机森林与该模型的元数据。模型源自历史 434 条记录、24 个文献组。服务启动时会核对 351 个预测和归档输出，并核对 SHAP 的加和关系。HUVEC接种数为2300个/孔，缺失标志为0；缺失的年份、合成路线由冻结预处理器处理。2026-11-03更新了七张数据表及在线预测输入，视频中的历史预测值不作为当前结果。

## 修改界面

`platform/studio.html` 是可直接运行的生成页面，`studio.css` 为主题样式，`studio.js` 为助手交互。`platform/ui/` 保存 React / shadcn/ui 组件、TSX 页面和生成模板。日常运行使用已经生成的 HTML。

修改 TSX 或模板后，使用 Node.js 22 或更新版本重新生成页面。

```powershell
cd platform/ui
npm install
npm run build
```

启动 Python 服务后刷新页面。静态组件在构建时由 React 渲染成 HTML，筛选、请求、问答和导出由页面脚本处理。

## 文件结构

```text
NanoTox-Assistant/
  videos/                 两版最终视频
  platform/               后端、页面及模型输入映射
    ui/                   shadcn/ui 组件与页面构建源文件
  data/                   运行所需的归档实验与解释表
  models/                 冻结随机森林及元数据
  requirements.txt        Python 直接依赖版本
  SHA256.json             交付文件校验值
```
