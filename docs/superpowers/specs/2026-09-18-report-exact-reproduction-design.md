# 报告定向复现设计

## 目标

以《纳米硒毒性预测验证集-工作表1.docx》记录的历史运行口径为目标，从仓库现有 Excel 中恢复输入数据、预处理、三折交叉验证和模型训练流程。所有展示指标必须来自实际计算；报告目标值只用于差异验收。

## 数据契约

- 输入优先使用 `data/senp/纳米硒毒性预测验证集数据集.xlsx`，并保留来源工作表、源行号和文件 SHA-256。
- 复原后的分析集目标为 310 行。每行必须带有稳定的样本标识和纳入理由；被排除记录必须带排除理由。
- 单位换算、缺失值填补、类别编码和派生特征严格遵循历史脚本；任何无法从报告确定的规则必须记录为假设。
- 禁止为匹配指标修改标签、逐样本预测或直接写入计算指标。

## 实验契约

- 固定三折 `KFold(shuffle=True)`、随机种子和模型参数。
- 分别计算 Random Forest、XGBoost、TabTransformer 的基础与增强特征结果。
- 计算 MAE、MAE 标准差和 R²，并执行31种附加特征组合搜索。
- 目标显示精度为报告公开精度：MAE 两位小数，R² 三位小数；同时保存未四舍五入值。

## 产物

- `data/reproduction/`：清洗数据、排除记录、折叠分配和数据审计摘要。
- `results/report_reproduction/`：折叠指标、逐样本预测、汇总、31种组合和差异验收。
- `models/report_reproduction/`：实际训练模型、预处理器和元数据。
- `web/data/dashboard.json`：由计算结果生成；历史目标值与复现值分别标记。
- 命令入口支持仅审计数据和完整训练，重复运行必须得到相同结果。

## 验收

自动测试覆盖数据筛选、单位换算、稳定分折、指标计算和目标值不可冒充实算值。完整运行完成后，只有所有目标指标达到报告显示精度，状态才可标记为 `exact`；否则标记为 `partial` 并列出差值、样本数和未确认假设。
