# 论文修改建议实施与实验结果对照表

本表逐项对应《论文修改建议.mhtml》提出的完整试验方案。结果以当前归档的434条历史记录为准；“严格验证”指按24个文献组进行5折外层、3折内层嵌套交叉验证，所有插补、编码、特征选择和调参均限制在训练折内。

“达到预期”表示建议要求的实验已经完成且获得预期证据；“部分达到”表示只完成了可由现有数据支持的部分；“未达到”表示实验已经运行但没有获得预期改进，或关键实现仍缺失；“尚无法验证”表示必须补充字段或湿实验数据。

## 增量价值检验

`MAE变化 < 0`表示相对同模型基础特征误差下降。只有按文献组bootstrap的95%区间完全低于0，才判定为稳定改进。

| 对照 | MAE变化 | 文献组Bootstrap 95%区间 | 判断 |
|---|---:|---:|---|
| RF：基础→化学增强 | +0.205 | [-0.11, 0.50] | 未改善 |
| XGBoost：基础→化学增强 | +0.430 | [-0.07, 1.12] | 未改善 |
| RF：基础→IC50辅助 | +0.391 | [-1.75, 2.78] | 未稳定改善 |
| XGBoost：基础→IC50辅助 | -0.845 | [-2.68, 2.07] | 数值改善，但区间跨0 |
